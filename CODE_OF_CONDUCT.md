# Code of Conduct - SplatPC-Splatoon-Native

If you are reading this, it is likely because you are interested in this project. First of all, welcome! However, let’s establish a few important rules for the well-being of our community.

This document outlines the expected standards of behavior, legal boundaries, and contribution guidelines for everyone participating in this *Splatoon* PC port project. By participating in this project (via commits, issues, pull requests, or community discussions), you agree to abide by these terms.

## 1. Primary Language Policy
- **English Only for Project Communications:** English is the official primary language of this project. All public communications, pull requests, issue descriptions, code reviews, discussions, commit messages, code comments, and documentation **must be written in English**.
- **Universal Standard:** Even if two or more members understand or speak another language, all project-related technical and public discussions must remain in English so that all maintainers, contributors, and auditors can follow and participate seamlessly.

## 2. Respect and Inclusivity
- **Community Standards:** Be respectful, welcoming, and considerate of all contributors, maintainers, and community members regardless of their background or language proficiency level.
- **No Abusive Pings/Mentions:** Do **NOT** unnecessarily ping, tag, or mass-mention other contributors, maintainers, or community members. Respect people's time and notification settings. Use pings only when strictly necessary and relevant.
- **Prohibited Behavior:** Harassment, discrimination, hate speech, personal attacks, trolling, or toxic behavior of any kind will not be tolerated.
- **Constructive Interaction:** Gracefully accept constructive feedback and focus on what is best for the community and project stability.

## 3. Conduct Towards Rightsholders and Third Parties
- **Zero Harassment Policy:** Do **NOT** harass, spam, tag, attack, or target employees, developers, representatives, or official social media accounts of Nintendo or any other copyright holders.
- **Professional Representation:** Any toxic, aggressive, or harassing behavior directed at rightsholders outside or inside this repository directly harms the project and will result in an immediate and permanent ban from the community.

## 4. Artificial Intelligence (AI) Policy
- **Text, Issues & Pull Request Descriptions (AI Forbidden):** Text written for issues, pull request descriptions, and general discussion must **NOT** be generated by AI. Only automatic translators (e.g., DeepL, Google Translate) are permitted, provided a human wrote the original text.
- **AI-Assisted Code Contributions (Allowed with Human Explanation):** Code contributions generated or assisted by AI are permitted **ONLY IF** a human contributor thoroughly understands the code and explicitly explains in detail what the changes add, how they work, and why specific modifications were made. Raw, unexplained AI code dumps will be rejected immediately.

## 5. Scope and Educational Purpose (What This Project Is NOT)
- **Educational & Interoperability Focus:** This project is developed strictly for research, educational, software preservation, and interoperability purposes.
- **Not a Piracy Tool:** This project is **NOT** designed, intended, or maintained to facilitate piracy, infringe upon intellectual property, or bypass digital rights management (DRM) for unauthorized gameplay distribution.

## 6. Legal and Copyright Compliance (Strict Policy)
To protect the project, maintainers, and contributors, strict adherence to intellectual property laws is required:

- **NO COPYRIGHTED ASSETS:** Do **NOT** commit, upload, host, link to, or share any copyrighted assets belonging to Nintendo or any third party (including but not limited to 3D models, textures, audio/soundtrack files, animation data, proprietary scripts, or original game binaries/code).
- **NO SCREENSHOTS OR OFFICIAL FOOTAGE:** Do not include official game screenshots, gameplay video captures, or promotional artwork in repository issues, pull requests, commits, or documentation. Use text descriptions, terminal logs, ASCII diagrams, or custom placeholder assets instead.
- **CLEAN ROOM REVERSE-ENGINEERING:** All source code submitted to this repository must be clean-room reverse-engineered or written entirely from scratch. Direct copy-pasting or distribution of decompiled source code from proprietary binaries is strictly prohibited.
- **NO ROM/DUMP DISTRIBUTION:** This repository does not provide, host, or assist in obtaining illegal game copies, keys, or ROMs. Do not request or share links to copyrighted ROMs or game dumps.

## 7. Contribution Guidelines
- **Code Style:** Ensure all code contributions strictly adhere to the project's coding standards and naming conventions (e.g., follow the rules specified by .clang-format).
- **Code Comments:** All code comments, documentation strings, commit messages, and technical explanations must be written **strictly in English**, regardless of your native language.
- **Quality & Integrity:** Test your changes locally before submitting a pull request to verify that the code compiles clean and does not introduce regressions or security hazards.

## 8. Reporting Issues & Enforcement
- **Private Reporting:** If you encounter inappropriate behavior, potential security vulnerabilities, or accidental copyright violations within the repository, do **NOT** post them publicly. Please report them immediately and privately to the project maintainers.
- **Primary Contact:** Reach out directly on Discord: **`sussy_0897`**
- **Enforcement & Sanctions:** Maintainers reserve the right to edit or remove any commit, comment, issue, or pull request that violates this Code of Conduct. Egregious or repeated violations may result in a permanent ban from contributing to or participating in the project organization.
